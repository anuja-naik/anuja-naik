## 🚀 Featured Projects

### 🏆 Digitwin.AI — AI Predictive Maintenance System
> **1st place, UpXGen Hackathon (PVGCOE Nashik)**

| | |
|---|---|
| **Problem** | Machine failures are costly when they're only caught after they happen. |

### 📡 Human Detection Using WiFi Signals
| | |
|---|---|
| **Problem** | Sensing human presence usually needs cameras or wearables, which raise privacy and cost concerns. |
| **What I built** | A camera-free sensing system that uses WiFi Channel State Information (CSI) captured with an **ESP32**, with a **Random Forest** classifier trained to recognise human activity (walking, sitting, standing) from signal patterns. |
| **Stack** | `Python` `ESP32` `Random Forest` `Signal Processing` `Machine Learning` |
| **Highlights** | Feature extraction from wireless signals · ML on embedded/IoT sensing data |
| **Links** | [Repository](https://github.com/anuja-naik/Human-Detection-Using-WiFi) |

### 💳 CreditWise — Loan Approval Prediction
| | |
|---|---|
| **Problem** | Predict whether a loan application will be approved from applicant financial and credit data. |
| **What I built** | An end-to-end pipeline covering EDA, preprocessing, and feature engineering (including engineered quadratic terms), deployed as an interactive Streamlit app for real-time predictions. |
| **Stack** | `Python` `Scikit-learn` `Streamlit` |
| **Highlights** | Compared 3 classifiers: **Logistic Regression 87.5%** (best) · Naive Bayes 86.5% · KNN 75.5% |
| **Links** | [Live Demo](https://creditwise-loan-prediction-system-mgd3savehoyqda7kf7rpub.streamlit.app/) · [Repository](https://github.com/anuja-naik/CreditWise-Loan-Prediction-System) |

### 🛒 SmartCart — Customer Segmentation System
| | |
|---|---|
| **Problem** | Group e-commerce customers into meaningful segments without labelled data. |
| **What I built** | An unsupervised pipeline with feature engineering (age, tenure, total spending, household composition), one-hot encoding, scaling and **PCA**. The number of clusters was chosen with the elbow method and silhouette score. I compared K-Means and Agglomerative Clustering and picked **K-Means** for its higher silhouette score. Segments were profiled by income and spending, then deployed on Streamlit. |
| **Stack** | `Python` `Scikit-learn` `K-Means` `Agglomerative Clustering` `PCA` `Streamlit` |
| **Links** | [Live Demo](https://shareappio-ktudjssrkceywppsmev2ck.streamlit.app/) · [Repository](https://github.com/anuja-naik/SmartCart-Customer-Segmentation-System) |
